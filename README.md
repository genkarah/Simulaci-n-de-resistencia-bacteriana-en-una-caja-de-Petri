
# Resistencia bacteriana en una caja de Petri

Proyecto educativo desarrollado en Python para simular y
visualizar la dinámica de poblaciones bacterianas sensibles
y resistentes a un antibiótico.

## Objetivo

Implementar un autómata celular estocástico donde cada celda
representa una bacteria sensible, una bacteria resistente
o un espacio vacío.

El proyecto utiliza como referencia conceptual la resistencia
de Streptococcus pyogenes a eritromicina.

## Tecnologías

- Python
- NumPy
- Matplotlib
- Pandas

## Estado del proyecto

En desarrollo.

Módulo 1: configuración del entorno y construcción de
una matriz para representar la caja de Petri.

## Nota

Simulación con fines educativos. No pretende predecir
la respuesta clínica o microbiológica a una dosis real.
